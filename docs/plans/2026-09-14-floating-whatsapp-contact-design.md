# Floating WhatsApp contact design

## Objective

Make the persistent WhatsApp access immediately understandable as a contact action.

## Approved design

- Replace the circular floating control with a compact green button.
- Display the existing WhatsApp logo followed by `Contactanos`.
- Preserve the existing WhatsApp destination, new-tab behavior, and accessible label.

## Verification

Run lint and a production build to confirm the component and responsive styles compile successfully.
